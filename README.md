# 🚀 ReviewAI — Твой личный помощник по отзывам

Привет! Я создал этот сервис, чтобы упростить жизнь владельцам малого бизнеса (кафе, магазины, сервисы). 

### Что умеет это приложение:
*   Генерировать отзывы: Если клиенту лень писать, вы можете помочь ему составить крутой текст за 5 секунд.
*   Отвечать на отзывы: Вежливо, официально или с юмором — нейросеть подберет правильный тон для ответа вашим клиентам.
*   Экономить время: Больше не нужно мучительно придумывать ответы, ИИ сделает это за вас.

### Как пользоваться:
1. Вставьте свой API-ключ (Hugging Face) в боковое меню.
2. Выберите тип задачи и опишите детали ситуации.
3. Нажмите кнопку и получите готовый текст!

---
*Сделано для того, чтобы бизнес мог больше общаться с клиентами, а не с клавиатурой.*
